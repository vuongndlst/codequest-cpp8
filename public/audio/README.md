# Âm thanh

Tám tệp `.ogg` chọn từ hai bộ của Kenney, đều **CC0 1.0** — dùng được cho cả
mục đích thương mại, ghi nguồn không bắt buộc. Dự án vẫn ghi nguồn.

| Tệp | Dùng khi | Bộ gốc |
|---|---|---|
| `step.ogg` | Nhân vật bước một ô | RPG Audio |
| `bump.ogg` | Đâm vào vật cản | Interface Sounds |
| `gem.ogg` | Nhặt được ngọc | Interface Sounds |
| `door.ogg` | Mở cửa / cổng | RPG Audio |
| `goal.ogg` | Tới đích, hoàn thành nhiệm vụ | Interface Sounds |
| `levelup.ogg` | Lên cấp, nhận huy hiệu | Interface Sounds |
| `error.ogg` | Code có lỗi | Interface Sounds |
| `click.ogg` | Bấm nút quan trọng | Interface Sounds |

Nguồn: https://kenney.nl/assets/interface-sounds · https://kenney.nl/assets/rpg-audio
Nguyên văn giấy phép: `kenney-LICENSE.txt`

**Định dạng `.ogg`**: nhẹ hơn `.mp3` ở cùng chất lượng và mọi trình duyệt hiện
hành đều phát được. Tổng tám tệp khoảng 83 KB.
